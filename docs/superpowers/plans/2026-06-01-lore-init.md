# /lore:init Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/lore:init` — scaffold a target repo's `.lore/`, copy the browser shell into `.lore/site/` (closing the serve-404 seam), and generate `config.yml` via component auto-discovery.

**Architecture:** One module `lib/init.js` holds pure, independently-testable functions (`scaffold`, `copyShell`, `ensureGitignore`, `discoverComponents`, `renderConfigYaml`) plus an `init` orchestrator and a CLI entry — mirroring the existing `serve.js`/`manifest.js` pattern. A thin `commands/lore-init.md` shells out to it. The post-commit hook is **deferred** (it depends on the not-yet-built journal subsystem).

**Tech Stack:** Node.js (ESM, `type: module`), `node:test` built-in runner (zero external deps), `node:fs`/`node:path`/`node:child_process`. No YAML library — `config.yml` is hand-rendered; `init` only checks its existence, never parses it.

**Spec:** `docs/superpowers/specs/2026-06-01-lore-init-design.md`. **Parent spec:** `docs/superpowers/specs/2026-05-31-lore-repo-wiki-design.md` §3/§5.5/§6/§7.

**Deliberate refinements vs spec wording** (preserve spec intent):
- `discoverComponents(repoRoot)` uses **real `fs` + temp-dir fixtures** in tests (not injected `deps`) — matches the `emitManifest` precedent in this repo. Output is identical; tests build a real temp repo and assert the returned roots.
- `code_roots` strings always use **forward slashes** (`src/pkg`, `packages/a`) regardless of OS, so config + dedup are platform-stable. `path.join` is used only for filesystem access, never for output strings.

**Module API contract (locked — later tasks must match exactly):**

`lib/init.js` (ESM exports):
- `scaffold(loreDir) -> void` — `mkdir -p` `journal/ wiki/ site/ .state/`. Idempotent.
- `copyShell(srcSiteDir, loreDir) -> string[]` — copy `index.html` + `shell.mjs` into `loreDir/site/` (overwrite); returns the filenames copied.
- `ensureGitignore(repoRoot) -> 'created'|'appended'|'present'` — ensure a `.lore/.state/` line in `repoRoot/.gitignore`.
- `discoverComponents(repoRoot) -> string[]` — sorted, deduped suggested `code_roots` (forward-slash dir paths). Layers: fallback + Python + JS workspaces.
- `renderConfigYaml(codeRoots) -> string` — hand-rendered `config.yml` per spec §5.
- `init({ repoRoot, srcSiteDir }) -> { loreDir, copied, codeRoots, configWritten, gitignore }` — orchestrates scaffold → copyShell → discover → (write config.yml only if absent) → ensureGitignore.

Internal helpers (not exported): `topDirs`, `dirHasCode`, `dedupeAncestors`, `isDir`, `discoverFallback`, `discoverPython`, `discoverJsWorkspaces`.

// append to lib/init.js
import { existsSync, readFileSync, writeFileSync, appendFileSync } from 'node:fs';

const IGNORE_LINE = '.lore/.state/';

export function ensureGitignore(repoRoot) {
  const p = join(repoRoot, '.gitignore');
  if (!existsSync(p)) {
    writeFileSync(p, IGNORE_LINE + '\n');
    return 'created';
  }
  const text = readFileSync(p, 'utf8');
  if (text.split(/\r?\n/).some(l => l.trim() === IGNORE_LINE)) return 'present';
  const sep = text === '' || text.endsWith('\n') ? '' : '\n';
  appendFileSync(p, sep + IGNORE_LINE + '\n');
  return 'appended';
}
```

// append to lib/init.js
import { readdirSync, statSync } from 'node:fs';
import { extname } from 'node:path';

const EXCLUDE = new Set([
  '.git', '.lore', 'node_modules', '.venv', 'venv', '__pycache__', '.pytest_cache',
  'dist', 'build', 'out', 'target', 'vendor', 'coverage',
  'docs', 'doc', 'tests', 'test', '__tests__', 'config', '.github', '.idea', '.vscode',
]);

const CODE_EXT = new Set([
  '.py', '.js', '.mjs', '.cjs', '.ts', '.tsx', '.jsx', '.go', '.rs',
  '.java', '.kt', '.rb', '.php', '.c', '.cc', '.cpp', '.h', '.hpp', '.cs', '.swift', '.scala', '.sh',
]);

function topDirs(repoRoot) {
  let entries = [];
  try { entries = readdirSync(repoRoot, { withFileTypes: true }); } catch { return []; }
  return entries
    .filter(e => e.isDirectory() && !e.name.startsWith('.') && !EXCLUDE.has(e.name))
    .map(e => e.name);
}

function dirHasCode(absDir, depth = 2) {
  let entries = [];
  try { entries = readdirSync(absDir, { withFileTypes: true }); } catch { return false; }
  for (const e of entries) if (e.isFile() && CODE_EXT.has(extname(e.name))) return true;
  if (depth > 1) {
    for (const e of entries) {
      if (e.isDirectory() && !e.name.startsWith('.') && dirHasCode(join(absDir, e.name), depth - 1)) return true;
    }
  }
  return false;
}

function dedupeAncestors(roots) {
  return roots.filter(r => !roots.some(o => o !== r && o.startsWith(r + '/')));
}

function discoverFallback(repoRoot) {
  const out = [];
  for (const d of topDirs(repoRoot)) if (dirHasCode(join(repoRoot, d))) out.push(d);
  return out;
}

export function discoverComponents(repoRoot) {
  const roots = new Set();
  for (const r of discoverFallback(repoRoot)) roots.add(r);
  return dedupeAncestors([...roots]).sort();
}
```

// append to lib/init.js
function discoverJsWorkspaces(repoRoot) {
  const pkgPath = join(repoRoot, 'package.json');
  if (!existsSync(pkgPath)) return [];
  let pkg;
  try { pkg = JSON.parse(readFileSync(pkgPath, 'utf8')); } catch { return []; }
  const ws = Array.isArray(pkg.workspaces) ? pkg.workspaces
    : Array.isArray(pkg.workspaces?.packages) ? pkg.workspaces.packages : [];
  const out = [];
  for (const pat of ws) {
    if (typeof pat !== 'string') continue;
    if (pat.endsWith('/*')) {
      const base = pat.slice(0, -2);
      const baseAbs = join(repoRoot, base);
      if (isDir(baseAbs)) {
        for (const e of readdirSync(baseAbs, { withFileTypes: true })) {
          if (e.isDirectory()) out.push(base + '/' + e.name);
        }
      }
    } else if (isDir(join(repoRoot, pat))) {
      out.push(pat);
    }
  }
  return out;
}

export function init({ repoRoot, srcSiteDir }) {
  const loreDir = join(repoRoot, '.lore');
  scaffold(loreDir);
  const copied = copyShell(srcSiteDir, loreDir);
  const codeRoots = discoverComponents(repoRoot);

  }
  const gitignore = ensureGitignore(repoRoot);
  return { loreDir, copied, codeRoots, configWritten, gitignore };
}
