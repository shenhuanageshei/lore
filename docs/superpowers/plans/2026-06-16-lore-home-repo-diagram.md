# HOME 图改造（工具流程图 → 本仓库架构总览）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 HOME 页那张硬编码的 lore 工具流程图，改成由 LLM 综合本仓库 component+flow 轴生成的「本仓库架构总览」图，并修正脚手架标题写死 `'lore'` 的 bug。

**Architecture:** 改两处硬编码（`home.js` 脚手架模板 + `runner.js` HOME 重写 prompt），让图自适应每个仓库；质量门已不强制 HOME 有图，无需改动、加测试坐实；`sync.js` 脚手架标题改取 `package.json.name`，回退仓库目录名。

**Tech Stack:** Node.js (ESM), `node:test` + `node:assert/strict`，纯字符串/模板改动，无新依赖。

参考 spec：`docs/superpowers/specs/2026-06-16-lore-home-repo-diagram-design.md`

---

## File Structure

- `lib/home.js` — `defaultHomePage` 脚手架：删 Knowledge flow mermaid 块，换占位节。
- `lib/runner.js` — `axisPrompt` 的 `byAxis.HOME`：prompt 从「Knowledge flow mermaid」改「本仓库总览」。
- `lib/sync.js` — `finalizeSync` 内读 package.json 处：标题取 `name`，回退 `basename(repoRoot)`。
- `test/home.test.js` — 更新脚手架断言 + 加 title H1 测试。
- `test/runner.test.js` — 更新 HOME axisPrompt 断言 + 加「HOME 无图不判失败」测试。
- `test/sync.test.js` — 加脚手架标题集成测试（含/不含 package.json 两 case）。

```js
test('finalizeSync: 脚手架 HOME 标题取 package.json name（无现有 HOME 时）', () => {
  const root = gitRepo();
  try {
    const lore = join(root, '.lore');
    mkdirSync(join(lore, 'wiki'), { recursive: true });
    writeFileSync(join(lore, 'config.yml'), 'language:\n  default: zh\n  available: [zh]\n');
    writeFileSync(join(root, 'package.json'), JSON.stringify({ name: 'my-cli', version: '1.2.3' }));
    finalizeSync(lore, '2026-06-06T00:00:00Z');
    const home = readFileSync(join(lore, 'wiki', 'HOME.md'), 'utf8');
    assert.match(home, /^# my-cli$/m);          // H1 用 package.json name，不再写死 lore
    assert.doesNotMatch(home, /^# lore$/m);
  } finally { rmSync(root, { recursive: true, force: true }); }
});

test('finalizeSync: 无 package.json 时 HOME 标题回退到仓库目录名', () => {
  const root = gitRepo();
  try {
    const lore = join(root, '.lore');
    mkdirSync(join(lore, 'wiki'), { recursive: true });
    writeFileSync(join(lore, 'config.yml'), 'language:\n  default: zh\n  available: [zh]\n');
    finalizeSync(lore, '2026-06-06T00:00:00Z');
    const home = readFileSync(join(lore, 'wiki', 'HOME.md'), 'utf8');
    assert.match(home, new RegExp('^# ' + basename(root) + '$', 'm'));
  } finally { rmSync(root, { recursive: true, force: true }); }
});
```

## 生效方式（代码改完后的运行时操作，非代码任务）

改 prompt 只影响**未来**的 HOME 重写。已存在的 `HOME.md`（如 mal-analyze-cli）要换图，需触发一次 HOME 重写：
- 壳控制台把该仓库切到 **auto 档**，让 portal ticker 在静默期消化重写队列（mal-analyze-cli 当前队列已堆 HOME.md + 9 页）；或
- 手动 `node lib/runner.js D:/workspace/mal-analyze-cli/.lore`（注意：会真调 claude CLI 逐页重写，耗时数分钟/页）。
